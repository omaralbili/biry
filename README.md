# بيري + Gemini API

## التشغيل
1. ثبّت Node.js 18 أو أحدث.
2. افتح Terminal داخل مجلد `biry`.
3. شغّل `npm start`.
4. افتح `http://localhost:4000`.

## الإصلاحات
- أي سؤال غير موجود في قاعدة المعرفة يذهب إلى Gemini.
- زر `🔎 أريد معرفة المزيد` أصبح يستدعي Gemini فعليًا.
- مفتاح Gemini لا يظهر في `app.js`؛ يتم قراءته من `.env` على الخادم.
- تمت إضافة Project Name وProject Number إلى إعدادات البيئة.
- تم تحديث التعليقات الخاصة بالتكامل.

## أمان
لا ترفع `.env` إلى GitHub أو أي استضافة عامة. وإذا نُشر المفتاح في مكان عام،
قم بتدويره/استبداله من Google AI Studio.
